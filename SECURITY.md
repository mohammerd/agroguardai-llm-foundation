# Security policy

Report suspected vulnerabilities privately to the repository owner through GitHub's private vulnerability reporting feature when available. Do not publish exploit details or sensitive farmer data in public issues.

Never commit API keys, access tokens, passwords, private datasets, personally identifying information, precise farm coordinates, private reviewer information, or partner-confidential material.

For agricultural safety concerns in model outputs, open a report that includes a minimal, non-identifying example, the model/data version, language, and potential harm. Do not include personal or farm-identifying details.
