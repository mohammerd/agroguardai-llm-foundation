# Data

This directory is reserved for datasets and their documentation. No legacy dataset has been migrated or cleared for public redistribution yet.

Dataset publication and training eligibility are separate:

- **Publication eligibility** requires documented rights to redistribute, privacy review, provenance, and a safe release format.
- **Training eligibility** additionally requires the required language, agronomy, evidence, and independent reviewer approvals, plus leakage and safety checks.

Do not add raw recordings, personal information, precise farm locations, confidential partner records, or unlicensed third-party content. See [data governance](../docs/DATA_GOVERNANCE.md) and [data contribution guidance](CONTRIBUTING.md).
